pixiv_bulk_downloader

pixiv-bulk-downloader

Pixiv Bulk Downloader for bookmarks and works of following authors.

Installation

# mise via github release
mise use -g github:eggplants/pixiv-bulk-downloader

# mise via pipx
mise use -g pipx:pixiv-bulk-downloader

# pipx
pipx install pixiv-bulk-downloader

# pip
pip install pixiv-bulk-downloader

Docker

docker pull ghcr.io/eggplants/pixiv-bulk-downloader

# the image has no browser, so log in by pasting the code back
docker run --rm -it -v ~/pbd:/root/pbd -v ~/.config/gppt:/root/.config/gppt \
  ghcr.io/eggplants/pixiv-bulk-downloader --oauth

Setup

Logging in is delegated to gppt, which owns the credentials and the token cache under ~/.config/gppt/.

# store an account: pixiv ID + password (e2e), or nothing at all (oauth)
gppt configure

CLI

$ pbd login          # or: pbd l
[+]: Opening browser for pixiv login ...
[+]: Logged in as: eggplant (@eggplants)

$ pbd following      # or: pbd f -- works of every artist you follow
$ pbd bookmarked     # or: pbd b -- everything you have bookmarked

Run pbd with no subcommand to log in and then be asked what to download:

$ pbd
[+]: Logged in as: eggplant (@eggplants)
[?]: Download all works of following? (766 artists) (y/N): y
[?]: Download all bookmarked works? (1909 works) (y/N): y

Downloads land in $SAVE_DIR (default ~/pbd), or wherever -o/--save-dir says:

  • <save dir>/following/<id>_<name>_<account>/ -- one directory per artist
  • <save dir>/bookmarks/ -- every bookmarked work

Files already on disk are skipped, so an interrupted run can just be started again.

Library

from pixiv_bulk_downloader import PixivBookmarksDownloader, login
from pathlib import Path

client = login()
PixivBookmarksDownloader(client, Path.home() / "pbd").download_all()

 61    def paginate(
 62        self,
 63        fetch: Callable[..., JsonDict],
 64        *,
 65        interval: float,
 66        **params: Any,  # noqa: ANN401
 67    ) -> Iterator[JsonDict]:
 68        """Walk a paginated pixiv endpoint, yielding one response body per page.
 69
 70        The query string of each `next_url` is fed straight back into `fetch`,
 71        which is why every endpoint used here takes its own paging parameters
 72        by keyword.
 73
 74        Args:
 75            fetch: The `AppPixivAPI` method to call.
 76            interval: Seconds to wait between pages.
 77            **params: Parameters for the first call.
 78
 79        Yields:
 80            The decoded body of each page.
 81
 82        Raises:
 83            PixivAPIError: If a page comes back as an error other than an
 84                expired token.
 85        """
 86        next_qs: dict[str, Any] | None = params
 87        while next_qs is not None:
 88            self.client.ensure_fresh()
 89            page = fetch(**next_qs)
 90            if "error" in page:
 91                message = str(page["error"].get("message") or page["error"])
 92                if "invalid_grant" not in message:
 93                    raise PixivAPIError(message)
 94                # The access token lapsed mid-run: a fresh one retries this page.
 95                self.client.refresh()
 96                continue
 97            yield page
 98            next_qs = self.aapi.parse_qs(page.get("next_url"))
 99            self.rand_sleep(interval)

64        # "my own account" endpoints are called with.

26    def download_all(self) -> None:
27        """Fetch the works of every followed artist, then download them."""
28        console.info("Fetching information of works of following artists...")
29        artists = self.retrieve_following()
30        console.info("Downloading works of following artists...")
31        total = len(artists)
32        for index, artist in enumerate(artists, start=1):
33            dirname = f"{artist['id']}_{artist['name']}_{artist['account']}".replace("/", "／")
34            console.info(f"[Artist]{console.counter(index, total)}: {dirname}")
35            self.download(artist["illusts"], self.save_dir / "following" / dirname)
36            console.drop_line()
37
38    def retrieve_following(self) -> list[ArtistInfo]:
39        """List every followed artist together with all of their illustrations.
40
41        Returns:
42            One entry per followed artist.
43        """
44        total = self.aapi.user_detail(self.client.user_id)["profile"]["total_follow_users"]
45        artists: list[ArtistInfo] = []
46        for page in self.paginate(
47            self.aapi.user_following,
48            interval=FOLLOWING_INTERVAL,
49            user_id=self.client.user_id,
50        ):
51            previews = page.get("user_previews")
52            if not previews:
53                console.warn("Artist info seems to be empty.")
54                continue
55            for preview in previews:
56                user = preview.user
57                console.status(f"[+]: {console.counter(len(artists) + 1, total)}: {user.name} (id: {user.id})")
58                artists.append(
59                    {
60                        "id": user.id,
61                        "name": user.name,
62                        "account": user.account,
63                        "illusts": self.retrieve_works(user.id),
64                    },
65                )
66                self.rand_sleep(FOLLOWING_INTERVAL)
67        return artists
