pixiv_bulk_downloader

pixiv-bulk-downloader

Pixiv Bulk Downloader for bookmarks and works of following authors.

Installation

# mise via github release
mise use -g github:eggplants/pixiv-bulk-downloader

# mise via pipx
mise use -g pipx:pixiv-bulk-downloader

# pipx
pipx install pixiv-bulk-downloader

# pip
pip install pixiv-bulk-downloader

Docker

docker pull ghcr.io/eggplants/pixiv-bulk-downloader

# the image has no browser, so log in by pasting the code back
docker run --rm -it -v ~/pbd:/root/pbd -v ~/.config/gppt:/root/.config/gppt \
  ghcr.io/eggplants/pixiv-bulk-downloader --oauth bookmarked

Setup

Logging in is delegated to gppt, which owns the credentials and the token cache under ~/.config/gppt/.

# store an account: pixiv ID + password (e2e), or nothing at all (oauth)
gppt configure

CLI

$ pbd login          # or: pbd l
[+] Opening browser for pixiv login ...
[+] Logged in as: eggplant (@eggplants)

$ pbd following      # or: pbd f -- works of every artist you follow
$ pbd bookmarked     # or: pbd b -- everything you have bookmarked

Downloads land in $SAVE_DIR (default ~/pbd), or wherever -o/--save-dir says:

  • <save dir>/following/<id>_<name>_<account>/ -- one directory per artist
  • <save dir>/bookmarks/ -- every bookmarked work

Files already on disk are skipped, so an interrupted run can just be started again.

Library

from pixiv_bulk_downloader import PixivBookmarksDownloader, login
from pathlib import Path

client = login()
PixivBookmarksDownloader(client, Path.home() / "pbd").download_all()

 48    def rand_sleep(base: float = 0.1, rand: float = 2.5) -> None:
 49        """Sleep for `base` seconds plus up to `rand` more, to stay under the rate limit.
 50
 51        A wait of at least `COUNTDOWN_THRESHOLD` seconds -- the one between
 52        artists is half a minute -- ticks a `zzz... (n/total)` line once a
 53        second so the run does not look stuck.
 54        """
 55        duration = base + rand * random.random()  # noqa: S311
 56        if duration < COUNTDOWN_THRESHOLD:
 57            time.sleep(duration)
 58            return
 59        ticks = math.ceil(duration)
 60        for tick in range(1, ticks + 1):
 61            console.status(f"[+] zzz... ({tick}/{ticks})")
 62            time.sleep(min(1.0, duration - (tick - 1)))
 63        console.clear_line()

 65    @staticmethod
 66    def ext_links(illust: JsonDict) -> list[str]:
 67        """Collect the original-size URL of every page of one work.
 68
 69        Args:
 70            illust: An `illust` object from the pixiv API.
 71
 72        Returns:
 73            One URL per page; single-page works give a one-element list.
 74        """
 75        links: list[str] = [page.image_urls.original for page in illust.meta_pages]
 76        return links or [illust.meta_single_page.get("original_image_url", illust.image_urls.large)]

 78    def paginate(
 79        self,
 80        fetch: Callable[..., JsonDict],
 81        *,
 82        interval: float,
 83        **params: Any,  # noqa: ANN401
 84    ) -> Iterator[JsonDict]:
 85        """Walk a paginated pixiv endpoint, yielding one response body per page.
 86
 87        The query string of each `next_url` is fed straight back into `fetch`,
 88        which is why every endpoint used here takes its own paging parameters
 89        by keyword.
 90
 91        Args:
 92            fetch: The `AppPixivAPI` method to call.
 93            interval: Seconds to wait between pages.
 94            **params: Parameters for the first call.
 95
 96        Yields:
 97            The decoded body of each page.
 98
 99        Raises:
100            PixivAPIError: If a page comes back as an error other than an
101                expired token.
102        """
103        next_qs: dict[str, Any] | None = params
104        while next_qs is not None:
105            self.client.ensure_fresh()
106            page = fetch(**next_qs)
107            if "error" in page:
108                message = str(page["error"].get("message") or page["error"])
109                if "invalid_grant" not in message:
110                    raise PixivAPIError(message)
111                # The access token lapsed mid-run: a fresh one retries this page.
112                self.client.refresh()
113                continue
114            yield page
115            next_qs = self.aapi.parse_qs(page.get("next_url"))
116            self.rand_sleep(interval)

131    def retrieve_works(
132        self,
133        target_id: int,
134        *,
135        progress: str | None = None,
136        known: Container[int] | None = None,
137    ) -> list[IllustInfo]:
138        """List the illustrations posted by one artist.
139
140        Args:
141            target_id: The artist's pixiv user id.
142            progress: Prefix of a transient line reporting how many works have
143                been listed so far; no line is printed when it is None.
144            known: Ids an earlier run already listed. Paging stops at the first
145                work in it: the endpoint answers newest first, so everything
146                from there on is what the earlier run saw.
147
148        Returns:
149            One entry per illustration, newest first -- every one of them, or
150            only the ones posted since `known` was collected.
151        """
152        works: list[IllustInfo] = []
153        suffix = ""
154        if progress is not None:
155            # The pages themselves carry no count, so the artist's profile is
156            # the only place the `n/total` denominator can come from.
157            total = self.work_count(target_id)
158            suffix = "" if total is None else f"/{total}"
159            console.status(f"{progress} - 0{suffix} works")
160            self.rand_sleep(WORKS_PAGE_INTERVAL)
161        for page in self.paginate(
162            self.aapi.user_illusts,
163            interval=WORKS_PAGE_INTERVAL,
164            user_id=target_id,
165            type="illust",
166        ):
167            for illust in page["illusts"]:
168                if known is not None and illust.id in known:
169                    return works
170                works.append({"id": illust.id, "title": illust.title, "links": self.ext_links(illust)})
171            if progress is not None:
172                console.status(f"{progress} - {len(works)}{suffix} works")
173        return works

175    def download(
176        self,
177        works: Iterable[IllustInfo],
178        save_path: Path,
179        *,
180        total: int | None = None,
181        limit: int | None = None,
182    ) -> int:
183        """Download every page of every work into one directory.
184
185        Files already on disk are left alone, so an interrupted run can simply
186        be started again.
187
188        `works` is consumed lazily, so a listing that is still being paged stops
189        being paged as soon as `limit` is reached.
190
191        Args:
192            works: What `retrieve_works` (or a bookmark listing) collected.
193            save_path: Directory to write into; created if missing.
194            total: Denominator of the progress counter. Needed when `works` is
195                an iterator; a list counts itself.
196            limit: Stop after this many works have actually yielded a file. The
197                pages of the work that reaches the limit are all downloaded.
198
199        Returns:
200            How many works something was actually fetched for; the ones already
201            on disk are not counted, so a zero means there was nothing new to
202            download.
203        """
204        if total is None:
205            works = list(works)
206            total = len(works)
207        save_path.mkdir(parents=True, exist_ok=True)
208        fetched = 0
209        for index, work in enumerate(works, start=1):
210            title = work["title"].replace("/", "／")
211            new = False
212            for link in work["links"]:
213                # `123_title_p0.png`: the page suffix is the tail of the original name.
214                fname = f"{work['id']}_{title}_{link.split('/')[-1].split('_')[-1]}"
215                console.status(f"[+] {console.counter(index, total)}: {title} - {fname}")
216                # `AppPixivAPI.download` answers False for a file it left alone.
217                new |= bool(self.aapi.download(link, path=str(save_path), fname=fname))
218            if not new:
219                continue
220            fetched += 1
221            if limit is not None and fetched >= limit:
222                break
223        console.clear_line()
224        return fetched

 96        """The listing an earlier run saved for one artist.
 97

100
